# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within GV Maker, please send an email to [security@example.com]. All security vulnerabilities will be promptly addressed.

Please include the following information in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Security Measures

GV Maker implements the following security measures:
- Input validation
- Secure file handling
- Error handling
- Regular dependency updates

## Responsible Disclosure

We follow responsible disclosure practices. Please allow us a reasonable amount of time to address the issue before publicly disclosing it.
